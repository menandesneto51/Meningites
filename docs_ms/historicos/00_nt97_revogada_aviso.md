## Aviso operacional CIEVS

Não use a NT 97 para decisões atuais de:

- definição de caso suspeito;
- contato próximo;
- surto comunitário/institucional de DM;
- quimioprofilaxia DM/Hib;
- vacinação pós-DIHib.

Para esses temas, consulte exclusivamente a **NT 154/2024** e os trechos vigentes do Guia/Informe/Caderno alinhados a ela.

A NT 97 pode permanecer no acervo apenas para rastreabilidade histórica de documentos e treinamentos antigos.
